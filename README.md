# Usefull Userscripts

This repository contains userscripts which are usefull (at least to me lol).

## Sites currently included

### Librus
- Dark mode
- Hide ads (articles)
- Redirect to login page always

### Installation

You can install the script in two ways:

1. **Manual installation:** Download the `user.js` file and import it into your userscript manager, such as [Violentmonkey](https://violentmonkey.github.io/) or [Tampermonkey](https://www.tampermonkey.net/).
2. **Greasy Fork:** Install it directly from [Greasy Fork](https://greasyfork.org/en/scripts/602936-better-librus) with just a few clicks!
